Guardrails

        
health = Σ ratio points (0–100)
healthy band → full weight · watch → 45%
debt-to-equity scored lower-is-better

        

          
Draft-only — the agent drafts analyst briefs, never publishes or circulates them; every brief waits for a human sign-off.

        

          
Rules decide, LLM advises — ratios, benchmarks, the health score and red flags are deterministic; the local model only writes the narrative.

        

          
Sector-relative bands — ratios are scored against sector benchmarks, not absolute thresholds (retail ≠ biotech margins).

        

          
Data-quality gate — statements must pass the assets = liabilities + equity integrity check (±2%) before scoring.

        

          
Separation of duties — the preparer can never sign off their own brief.

        

          
Not investment advice — internal financial-health assessments only; no buy/sell recommendations exist in the code path.
